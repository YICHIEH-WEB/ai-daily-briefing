Anthropic launches Claude Ship, letting AI agents review, fix and approve code changes

Anthropic 11 月 23 日推出 Claude Ship，由已正式上線的 Code Review 加上新 Beta 工具 PR Steward 與 Claude Approvals 組成，AI 代理可審查 GitHub 拉取請求、修復未通過的檢查與合併衝突，並依團隊政策核准例行變更；即日起展開 Beta，適用 Claude Team 與 Enterprise 方案。

Anthropic 11 月 23 日推出 Claude Ship，讓 AI 代理從寫程式延伸到交付程式碼：它可審查 GitHub 拉取請求（PR）、修復未通過的檢查與合併衝突，並依團隊預設的政策核准例行變更。產品由三個部分組成：已正式上線的 Code Review，加上新進入 Beta 的 PR Steward 與 Claude Approvals。

PR Steward 會在拉取請求出現問題時主動介入，修復測試失敗或合併衝突；Claude Approvals 則讓團隊為例行變更設定核准規則，符合條件的變更可由代理直接放行，不再逐一等待人工點頭。Anthropic 同時推出 /ship 指令，讓開發者直接在 Claude Code 中呼叫這套流程。

Claude Ship 即日起展開 Beta，適用 Claude Team 與 Enterprise 方案。Anthropic 將其定位為「交付代理」而非單純的寫碼助手，目標是縮短從寫完程式到合併上線之間的等待時間。

這是 Anthropic 在上市後首週的又一產品動作：同一天，公司亦將企業前沿保障（EFS）推向公開測試版（見本期第 10 條），顯示其正同步擴張開發者工具與企業安全兩條產品線。

Z.ai's GLM-5.4 aims to match models up to four times its size by running 28 layers twice

智譜 Z.ai 11 月 23 日發布 GLM-5.4，750B 規模的首個 Loop Transformer 旗艦模型，將 GLM-5 基座的 28 層共享權重循環執行兩遍，在不增加參數的情況下加深計算深度，官方稱智能水平可對標 2 至 4 倍參數規模的模型；已上線 GLM Coding Plan、ZCode 與 Z.ai Chat，支援 100 萬詞元上下文。

智譜 Z.ai 11 月 23 日發布 GLM-5.4，官方稱為首個 Loop Transformer 架構的旗艦模型。模型規模為 750B 參數，將 GLM-5 基座的 28 層共享權重循環執行兩遍，以相同的參數量換取更深的計算深度，藉此提升推理能力。

官方稱，GLM-5.4 的智能水平可對標 2 至 4 倍參數規模的模型，並以此開啟「通用化編程」，讓程式碼生成影片、遊戲、CAD 與 3D 內容。模型支援 100 萬詞元上下文，已上線 GLM Coding Plan、ZCode 與 Z.ai Chat。

值得注意的是，官方並未公布旗艦版的基準成績表，效能主張目前僅為廠商說法，尚無第三方複核。標準 API 標示即將推出，模型權重計畫在完成安全加固後開放。

GLM-5.4 是繼 GLM-5 之後智譜在旗艦模型上的新動作，也是中國大模型廠商在「以更少參數換取更深推理」路線上的代表作。Hacker News 當日討論熱度超過千分，顯示海外開發者社群亦密切關注。

04開源

OpenAI 與 Cisco 開源 Shirudo，以 eBPF 即時防護 Linux 系統

Introducing Shirudo

OpenAI 與 Cisco 11 月 23 日聯合推出開源專案 Shirudo（日文「盾」），以 eBPF 在修補程式完成前先為運行中的 Linux 系統部署臨時「防護罩」，阻擋漏洞利用且無需重啟服務；由 AI 代理生成的防護罩已在受控測試中擋下 Java4Shell 對 Elasticsearch 的攻擊，採 BSD 2-Clause 授權。

OpenAI 與 Cisco 11 月 23 日聯合推出開源專案 Shirudo（日文「盾」），目標是縮短「發現漏洞」與「完成修補」之間的空窗期。Shirudo 以 eBPF 技術在運行中的 Linux 核心部署小型、經簽署的臨時「防護罩」，直接阻擋漏洞利用的程式路徑，服務無需重啟。

與傳統修補流程不同，防護罩由 AI 代理撰寫與測試：代理讀取漏洞資訊後生成 eBPF 程式，經簽署後部署，待正式修補程式上線再行撤除。OpenAI 表示，Codex 生成的防護罩已在受控測試中擋下 Java4Shell 對 Elasticsearch 的攻擊，Cisco 方面亦稱已擋下 PHP 相關漏洞的利用嘗試。

Shirudo 源自 Cisco 旗下 Isovalent 團隊 2022 年開源的 Tetragon，改寫為「代理原生」設計：代理直接以程式碼而非人類制定的政策語言與系統互動。專案採 BSD 2-Clause 授權，程式碼已公開於 GitHub，部署前仍須人工簽署核准。

兩家公司將 Shirudo 定位為「自我防禦基礎設施」的第一步，未來將持續合作。對企業而言，這意味著漏洞修補的責任分工正在改變：代理先擋下攻擊，人類再從容完成正式修補。

亞馬遜 11 月 23 日宣布，將收購以色列新創 Decart 的 Decart Optimization Stack（DOS）技術，並延攬三位共同創辦人與 AI 研究工程團隊。DOS 是一套最佳化軟體，可讓 AI 模型在輝達、亞馬遜與 Google 等不同廠商的晶片上更有效率地運行，並在晶片之間輕鬆切換。

亞馬遜未公布交易金額，彭博引述知情人士報導約 75 億美元；交易須經監管核准，且據報與五年期績效目標掛鉤。Decart 成立於 2023 年，上一輪估值據 PitchBook 資料接近 40 億美元。

這筆交易並非收購 Decart 整家公司：Decart 的 AI 模型（包括即時世界模型 Oasis）不在交易範圍內。技術將由亞馬遜晶片部門 Annapurna Labs 接手，用於提升 Trainium 與 Inferentia 晶片的效能。

亞馬遜表示，Decart 團隊自 2025 年起已與其合作，目標是讓 Trainium 更容易為開發者與企業採用。隨著亞馬遜準備對外銷售 Trainium，這筆交易形同買下晶片的「軟體入口」，是大型科技公司爭奪 AI 人才與基礎設施的又一例證。

AWS 11 月 23 日發布 Strands Decider v2，共五款開放權重模型，以 Google 的 Gemma 4 為基座，規模自 E2B 至 31B，採 Apache 2.0 授權，權重已上架 Hugging Face。與一般語言模型不同，Decider 是「系統一」模型：不生成文字，而是在一次前向傳遞中為開發者提供的選項逐一評分，最多可處理 255 個選項。

v2 的關鍵改進在於讀取情境的方式：它會雙向讀取完整情境，讓前面的細節能以後面的資訊重新詮釋，藉此捕捉足以翻轉答案的單一關鍵細節。AWS 報告，最大 31B 模型在 Decision Index 0.3 公開基準拿下 71.5 分，遠高於 v1 最大模型的 48.8 分；在 DecisionPivot 基準上則為 84.3 分，對 v1 的 23.2 分。

訓練資料共 1,750 萬筆決策範例，六項公開文字基準平均 82.1 分，高於 v1 的 70.0 分。AWS 亦稱，內部最大票務系統以 Decider 取代 Claude Sonnet 4.6 進行工單標籤後，成本降低 98%、回應速度提升 78%。不過這些數字皆為廠商自報，尚未經第三方複核。

同日，AWS 亦推出 Strands Box CLI，為 Claude Code、Codex 與 Kiro 等編碼代理提供原生沙箱支援。Decider v2 與 Box 的組合，顯示 AWS 正系統性地降低代理決策的推論成本，同時收緊無人值守編碼的安全邊界。

METR：AI 判斷力成瓶頸，遞迴自我改進未必來得那麼快

The Download: the AI judgment problem, carbon removal, and a crop threat

AI 評測非營利組織 METR 11 月 23 日更新時間跨度圖，在加入設計 AI 評測、哲學論證評分等開放式任務後，模型在需要判斷力的任務上明顯弱於寫程式；MIT Technology Review 指出，這意味著遞迴自我改進可能沒那麼快到來。

AI 評測非營利組織 METR 11 月 23 日更新其時間跨度（time horizon）圖，納入設計 AI 評測、哲學論證評分等開放式任務。結果顯示，模型在需要判斷力的任務上，明顯弱於寫程式等結構化任務。

時間跨度圖衡量模型可獨立完成多長的任務；先前版本以程式任務為主，模型表現持續拉長。但加入開放式任務後，曲線明顯放緩：當任務沒有明確對錯、需要權衡與取捨時，模型的表現大幅下滑。

MIT Technology Review 在當日的 The Download 中指出，這意味著遞迴自我改進——AI 自行設計更好的 AI 評測與訓練流程——可能沒那麼快到來。判斷力缺口成為模型能力曲線的新瓶頸。

這份更新與 OpenAI 首席科學家日前「以困惑度為共同尺度」的提議形成對照：一方主張以單一指標衡量進展，另一方則指出，進展本身在開放式任務上並不均勻。兩者共同指向同一個問題——現有評測能否捕捉 AI 真正的能力邊界。
